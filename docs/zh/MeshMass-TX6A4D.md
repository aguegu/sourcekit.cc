## 概述

Sourcekit® MeshMass TX6A4D 是一款可编程的遥控发射器模块，专为遥控爱好者、STEM教育和3D打印社区设计。它是MeshMass系列中首款经济实惠的可编程遥控解决方案产品。

TX6A4D 配备双摇杆、旋转旋钮和可编程按钮，非常适合为玩具、积木搭建和3D打印车辆构建自定义遥控系统。

![TX6A4D 控制器](/images/MeshMass-TX6A4D/main.jpg)

## 特性

- **双摇杆**: 两个双轴摇杆提供4个模拟输入通道
- **旋转旋钮**: 2个旋钮提供2个模拟输入通道，可编程用于油门、速度或参数调节
- **可编程按钮**: 4个肩部按钮 + 2个摇杆按压按钮支持自定义功能
- **OLED显示接口**: 6针SH1.0连接器支持128x64 SPI OLED（单独出售），显示电池电压、信号强度和原始输入值
- **Type-C充电**: 内置1S LiPo电池充电电路
- **天线选项**: 板载PCB天线 + IPEX-1接口用于外接2.4GHz天线
- **连接丢失报警**: 蜂鸣器在接收器连接丢失时发出警报
- **M2.5安装**: 4个安装孔用于安全固定

## 规格

| CPU 速度 | 48 MHz (典型值) |
| 内存 | 32KB SRAM, 256KB Flash |
| 无线 | 2.4GHz专有协议（原始PHY层实现最低延迟） |
| ADC | 12位, 8通道（6个用于摇杆/旋钮） |

## 配对

MeshMass TX6A4D 使用安全的一对一配对系统在发射器和接收器模块之间建立独占无线连接。配对系统确保可靠通信并防止附近其他设备的干扰。

### EEPROM存储

配对信息存储在 **EEPROM**（电可擦可编程只读存储器）中，这是一种非易失性存储器，即使断电也能保留数据。一旦 TX6A4D 发射器与 RX4M4S 接收器配对，它们的连接信息会在电源循环和重启后保持。这意味着您无需每次使用时重新配对设备——当两个设备通电时，已建立的连接会自动恢复。

### 一对一独占配对

MeshMass 配对是**双向且独占的**：
- 当发射器与新接收器配对时，它将失去对之前配对的任何接收器的访问权限
- 当接收器与新发射器配对时，其之前的发射器将无法再控制它

这种一对一关系确保每个发射器一次仅控制一个接收器，每个接收器仅响应一个发射器。如果您需要同时控制多个接收器，则需要多个发射器模块。

### 配对流程

要将 TX6A4D 发射器与 RX4M4S 接收器配对：

1. **在第一个设备上进入配对模式**：
   - 按下并按住**配对按钮**超过**5秒钟**
   - OLED屏幕将指示配对模式（通常显示"PAIRING"或类似信息）

2. **在第二个设备上进入配对模式**：
   - 当第一个设备处于配对模式时，按下并按住第二个设备上的**配对按钮**
   - 该设备也将进入配对模式并有相应的屏幕指示

3. **自动身份交换**：
   - 当两个设备都处于配对模式且在无线范围内时，它们会自动交换身份信息
   - 此过程通常在几秒钟内完成

4. **返回正常操作**：
   - 两个设备自动退出配对模式并返回正常操作
   - OLED显示屏恢复显示输入值和通道数据
   - 设备现已配对并准备使用

**注意**：配对按钮在 PCB 上标记为"PAIR"，与可编程肩部按钮（BTN0-BTN3）分开。它由固件控制，不能重新编程用于其他功能。

**动手学习流程**
```c
// 学生编写此代码：
void loop() {
  // 数学：通过除法进行线性缩放
  setChannel(0, getStick(0) / 2);

  // 物理：指数响应实现精细控制
  int8_t val = getStick(1);
  int8_t sign = (val > 0) ? 1 : ((val < 0) ? -1 : 0);
  setChannel(1, (val * val * sign) / 127);

  // 逻辑：双按钮安全系统
  if (getButton(0) && getButton(3)) {
    setChannel(2, getStick(2));  // 仅当两个安全按钮都按下时启用
  } else {
    setChannel(2, 0);  // 紧急停止
  }
}
```

**即时物理反馈**
- 代码更改 → 即时车辆响应
- 通过观察车辆移动进行调试
- **可视化调试**：在OLED显示屏上实时观察输入和通道值更新（即使没有连接电机/舵机）

## 固件框架

TX6A4D运行预构建的固件框架，该框架处理底层硬件操作，同时为应用编程提供简单的API。固件框架的关键方面包括：

### 通道系统
固件定义了16个有符号字节（-128至127）作为无线通道。这些通道构成发射器和接收器之间的通信桥梁。值-128被`getStick()`输出避免使用，以实现清洁的方向反转，但通道可以设置为-128用于特殊用途（例如电机控制中的刹车）：
- 通道 0-5：通常映射到模拟输入（摇杆、旋钮）
- 通道 6-15：可用于自定义映射（按钮、逻辑、混合）

**PCB标签:** PCB上标有STK0-STK5用于模拟输入和BTN0-BTN3用于数字按钮，与API索引直接对应。

**模拟输入映射** (通过 `getStick(n)`):
| 索引 | PCB标签 | 物理输入 | 描述 |
|------|---------|----------|------|
| 0 | STK0 | 右摇杆 X轴 | 右摇杆左右移动 |
| 1 | STK1 | 右摇杆 Y轴 | 右摇杆上下移动 |
| 2 | STK2 | 左摇杆 Y轴 | 左摇杆上下移动 |
| 3 | STK3 | 左摇杆 X轴 | 左摇杆左右移动 |
| 4 | STK4 | 左旋钮 | 旋转旋钮，通常用于油门 |
| 5 | STK5 | 右旋钮 | 旋转旋钮，通常用于参数调节 |

**数字输入映射** (通过 `getButton(n)`):
| 索引 | PCB标签 | 物理输入 | 描述 |
|------|---------|----------|------|
| 0 | BTN0 | 按钮0 (左侧边缘) | 可编程肩部按钮 + 左摇杆按压 |
| 1 | BTN1 | 按钮1 (左侧中间) | 可编程肩部按钮 |
| 2 | BTN2 | 按钮2 (右侧中间) | 可编程肩部按钮 |
| 3 | BTN3 | 按钮3 (右侧边缘) | 可编程肩部按钮 + 右摇杆按压 |
| - | PAIR | 配对按钮 | 系统按钮（固件控制） |

**注意:** 摇杆按压按钮与肩部按钮并联连接：
- **左摇杆按压**：激活 `getButton(0)`（与按钮0 / 左侧边缘按钮相同）
- **右摇杆按压**：激活 `getButton(3)`（与按钮3 / 右侧边缘按钮相同） |

### 应用程序代码示例
框架提供简单的API用于读取输入和设置通道。用户可以完全灵活地映射输入到通道，实现复杂的控制行为。以下是一个展示各种映射技术的示例，使用标准的stdint.h类型：

**架构说明：** TX6A4D上的代码仅控制从物理输入（摇杆、旋钮、按钮）到无线通道的映射。这些通道值如何在接收器模块（RX）或车辆上解释和反映，取决于运行在RX模块上的应用程序代码。

**注意：** `app.h` 头文件已经包含了 `<stdbool.h>` 和 `<stdint.h>` 头文件，因此您无需在应用程序代码中包含它们。在 meshmass.com 上，您可以查看 `app.h` 文件作为参考，但不建议编辑它。

**时序说明：** `loop()` 函数每20ms调用一次（每秒50次，即50Hz），与模拟舵机的典型更新频率相匹配。这种一致的时序确保平滑的控制更新。

**固件周期详情：** 在每次 `loop()` 调用之前，固件会自动刷新所有模拟输入（摇杆、旋钮）和数字输入（按钮），将其最新值存储在内存中。`getStick()` 和 `getButton()` 函数只是返回这些预先获取的值。在 `loop()` 期间，`setChannel()` 更新16字节传输帧缓冲区中的值。未明确设置的通道保持其先前值。`loop()` 完成后，整个帧缓冲区（所有16个int8_t通道值）将无线广播发送。

**重要提示：** 避免在 `loop()` 函数中使用忙等待或延时函数。固件在后台运行实时操作系统（RTOS）。阻塞操作会阻止关键系统任务运行，可能导致系统故障或不可预测的行为。

```c
#include "app.h"

// 需要在loop()调用之间保持值的变量应声明为全局变量
// 或在loop()内部使用'static'关键字声明
static bool button2_was_pressed = false;  // 跟踪按钮2按下状态

void loop() {
  // 示例1: 直接映射 - 摇杆0控制通道0
  setChannel(0, getStick(0));

  // 示例2: 反向映射 - 摇杆1控制通道1，方向反转
  setChannel(1, -getStick(1));

  // 示例3: 缩放映射 - 摇杆2控制通道2，灵敏度减半
  setChannel(2, getStick(2) / 2);

  // 示例4: 混合控制 - 使用摇杆3进行辅助控制
  setChannel(3, getStick(3));

  // 示例5: 死区处理 - 忽略小的摇杆移动
  if (abs(getStick(4)) > 10) {
    setChannel(4, getStick(4));
  } else {
    setChannel(4, 0);
  }

  // 示例6: 按钮控制的通道6 (递增/递减)
  if (getButton(0) && getChannel(6) < 127) {
    setChannel(6, getChannel(6) + 1);
  }
  if (getButton(1) && getChannel(6) > -127) {
    setChannel(6, getChannel(6) - 1);
  }

  // 示例7: 按钮锁存 - 在按钮按下时切换通道7
  if (getButton(2) && !button2_was_pressed) {
    setChannel(7, -getChannel(7)); // 在正负值之间切换
    button2_was_pressed = true;    // 标记按钮为按下状态
  }
  if (!getButton(2)) {
    button2_was_pressed = false;   // 按钮释放时重置
  }

  // 示例8: 复杂混合 - 组合多个输入用于坦克转向
  // 右摇杆和左摇杆垂直轴平均用于差速驱动车辆
  setChannel(8, (getStick(1) + getStick(2)) / 2);

  // --- 高级混合示例 ---

  // 示例9: 指数响应用于精细控制
  // 平方摇杆值（保留符号）实现非线性响应
  int8_t stick_val = getStick(5);
  int8_t sign = (stick_val > 0) ? 1 : ((stick_val < 0) ? -1 : 0);
  setChannel(9, (stick_val * stick_val * sign) / 127);

  // 示例10: 双按钮安全锁存 - 需要两个按钮同时按下
  // 按钮3作为安全开关，必须按住同时按钮2触发动作
  if (getButton(3) && getButton(2)) {
    setChannel(10, 127);  // 安全+触发按下时全速前进
  } else {
    setChannel(10, 0);    // 否则停止
  }
}
```

### API 函数
- `int8_t getStick(uint8_t n)`：返回模拟输入 `n` (0-5) 的有符号8位值 (-127 到 127)。值-128被固件避免使用，以实现清洁的方向反转。
- `bool getButton(uint8_t n)`：返回布尔值 `false`（未按下）或 `true`（按下）用于数字按钮 `n` (0-3)
- `int8_t getChannel(uint8_t n)`：返回通道 `n` (0-15) 的当前有符号8位值
- `void setChannel(uint8_t n, int8_t value)`：将通道 `n` 设置为 `value` (-128 到 127)。注意：虽然`getStick()`避免使用-128以实现清洁的方向反转，但`setChannel()`可以使用-128用于特殊用途，如电机控制中的刹车。
- `void loop()`：应用程序主循环函数，每20ms（50Hz）调用一次。实现此函数以定义控制逻辑。

**状态持久性**：需要在 `loop()` 调用之间保持值的变量应声明为 `static` 在 `loop()` 内部或作为全局变量在函数外部声明。

**标准库**：常见的C标准库函数如 `abs()` 可用于数学运算。

API支持灵活的映射：
- **直接映射**：`setChannel(0, getStick(0))`
- **反向方向**：`setChannel(1, -getStick(1))`
- **缩放灵敏度**：`setChannel(2, getStick(2) / 2)`
- **死区处理**：基于输入阈值有条件地设置通道
- **按钮锁存**：使用状态变量在按钮按下时切换通道
- **按钮递增/递减**：通过按钮按下调整通道值
- **指数响应**：非线性映射用于精细控制（例如 `(摇杆值*摇杆值)/127`）
- **双按钮安全**：要求多个按钮同时按下用于安全关键功能
- **复杂混合**：通过数学运算组合多个输入

### 固件管理的功能
框架自动处理多个系统功能：
- **OLED显示**：实时调试显示，展示电池电压、无线信号强度和所有输入值（6个模拟值：-127至127，4个数字值：0/1）。RX4M4S显示所有16个通道值（-128至127）用于完整的系统检查。显示原始十进制数值（非简化可视化），便于精确代码验证。OLED单独出售，对于固定安装是可选的，同时保持预算友好的灵活性。
- **蜂鸣器**：提供连接丢失警报和系统反馈
- **无线通信**：管理2.4GHz数据包传输与自动跳频
- **电池管理**：监测电压并提供低电量警告

这种分离让用户能够专注于应用逻辑（通道映射），而固件处理硬件复杂性。

## 系统架构

MeshMass系统将发射器和接收器的关注点分离：

- **TX6A4D (发射器)**: 将物理输入（摇杆、旋钮、按钮）映射到无线通道
- **RX4M4S (接收器)**: 将接收到的通道映射到物理输出（电机、舵机）

这种抽象让用户能够专注于特定构建中最重要的部分，而无需担心RF协议细节。
